# 🎄 마니또.xlsx

링크 하나로 참여하는 크리스마스 마니또 사이트.

- 🎯 미션형: 기간 동안 미션(미션 DB 50개 중 랜덤)·위시리스트, 끝나면 예상 마니또 맞히기
- 🎁 선물교환형: 마니또 지정만, 금액 상한 설정, 만나는 날 선물 교환

## 구성
- 화면: `index.html`, `style.css`, `app.js` (빌드 없음, GitHub Pages로 배포)
- DB: Supabase (`supabase-schema.sql`을 SQL Editor에서 실행)
- 연결 정보: `config.js` (공개용 publishable 키만 사용)

## 보안
- 데이터 테이블은 API에 노출되지 않는 `app` 스키마에 있고, 사이트는 RPC 함수만 호출합니다.
- 개인 링크 토큰으로 본인 확인. 매칭 결과는 본인 것만 보이고, 대표도 정답 공개 전에는 볼 수 없습니다.
